# C++ media library

A little media-library program I wrote for a data-structures course back in 2022.
You keep a catalogue of Blu-rays and books, a list of people, and you can lend
things out and get them back through a simple text menu.

I liked this project. The whole thing is built around a self-made doubly-linked
list that I wrote by hand instead of using the STL, and everything else hangs off
of that.

## Run it

```bash
./Starter.sh
```

That compiles everything with g++ and drops you into the menu. Comments are
partly in German — it's course code from 2022.
